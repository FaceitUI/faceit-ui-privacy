# История изменений

Все заметные **публичные** изменения расширения FACEIT UI. Только визуальный слой, если не указано иное.

## 0.4.0 — Unreleased — 2026-09-04

### Новый интерфейс
- Переработана панель New UI: разделы и навигация Custom стали понятнее и удобнее.
- В настройках доступны цвета и прозрачность для поддерживаемых тем и элементов.
- Полировка текстов и подписей панели на RU и EN.

### Фоны и GIF
- Улучшены фоны и GIF: удобнее выбирать, просматривать и править в редакторе.
- Исправлена загрузка GIF при цвете `#000000` (чистый чёрный больше не ломает медиа).

### Отчёты об ошибках
- Можно выбрать элементы на странице и приложить их список к отчёту для диагностики — только если отметить соответствующую галочку.
- Валидация формы отчёта стала понятнее: сразу видно, чего не хватает перед отправкой.
- Разрешения браузера нужны для отображения FACEIT UI и для явно выбранных пользователем возможностей отчёта.

## 0.3.0 — Unreleased — 2026-09-02

### Новый интерфейс
- Обновлена панель FACEIT UI: настройки стало проще находить по разделам.
- Для готовых тем добавлены компактные настройки прозрачности.
- Панель можно перетаскивать по странице, если она мешает.

### Фоны и GIF
- Для GIF-фонов появился режим повторения: небольшая GIF заполняет выбранный блок без растягивания.

### Отчёты об ошибках
- По желанию к отчёту можно приложить технический снимок с настройками расширения — только если отметить галочку.
- По желанию можно приложить скриншот текущей вкладки FACEIT — только если отметить галочку. Первая отправка может занять до 30 секунд.
- Форма отчёта стала компактнее, а причины ошибок отправки понятнее.
- Разрешения браузера нужны для отображения FACEIT UI и для явно выбранных пользователем возможностей отчёта (например скриншот).

### Исправления
- Улучшена работа прозрачных фонов при открытии профилей и вложенных страниц.
- Исправлено перемещение панели настроек.

## 0.2.1 — Unreleased — 2026-09-01

- Улучшена загрузка тем: убрана заметная светлая вспышка при обновлении страницы; изображения стабильнее загружаются при смене тем и пресетов.
- Улучшены импорт и экспорт пресетов.
- В панели расширения добавлена кнопка **GitHub**.
- Обновлена иконка расширения в браузере.
- Улучшена читаемость темы **Mono** при изменении яркости.

## 0.2.0 — Release — 2026-08-31

- Версия расширения обновлена до **0.2.0**.
- **Bug Report** (opt-in): добровольные отчёты из панели FACEIT UI с явным согласием; автоматической телеметрии нет.
- Доставка Bug Report через HTTPS intake (Cloudflare Worker → Render → email); для intake нет фонового service worker.
- `host_permissions` только для production intake endpoint (плюс зарезервированный `intake.faceit-ui.app`).
- Политика конфиденциальности обновлена с учётом потока данных Bug Report (этот репозиторий).

## 0.1.0 — Release — 2026-08-29

- Первый упакованный релиз **Chrome MV3**.
- Визуальный слой для `https://www.faceit.com/*` (темы, панель, локальные настройки).
- Одно разрешение: **`storage`** (`chrome.storage.local` для тем и настроек).
- Темы: Original, Soft Light, Graphite, Rainbow и Custom; язык панели RU/EN.
- Импорт / экспорт настроек пользовательской темы (Custom).
- Без фонового service worker; исполняемый код только в пакете расширения.
