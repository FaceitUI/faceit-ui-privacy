# FACEIT UI — Политика конфиденциальности

**Последнее обновление: 4 сентября 2026 г.**

FACEIT UI — браузерное расширение, которое добавляет слой оформления и настройки для [faceit.com](https://www.faceit.com). Эта политика описывает, какие данные обрабатывает расширение.

## Локальное использование (не передаётся)

- Настройки тем и панели, данные пользовательской темы, медиатека и пресеты хранятся локально в браузере (`chrome.storage.local`).
- FACEIT UI **не** выполняет автоматическую телеметрию и фоновый сбор данных.
- Визуальные изменения страниц FACEIT применяются локально. Расширение **не** отправляет автоматически HTML/DOM страницы, скриншоты, cookies, данные аутентификации или сессии FACEIT, полное содержимое хранилища расширения или историю просмотров.

## Bug Report (добровольно, по согласию)

Функция **Bug Report** в панели FACEIT UI — единственный способ, которым расширение передаёт данные за пределы вашего устройства.

**Когда отправляется:** только после заполнения обязательного описания, установки галочки согласия и нажатия **Send**.

**Цель:** сообщения об ошибках и поддержка расширения.

### Базовый отчёт (всегда при отправке)

- **Описание** проблемы (обязательно)
- **Шаги воспроизведения** (необязательно)
- **Контактные** данные (необязательно; например email или Telegram для ответа)
- **URL текущей страницы** на момент отправки
- **User-agent** браузера
- **Версия** расширения, **локаль** панели, **тема**, **категория** бага и **метка времени** отправки

### Необязательные вложения (только если вы отметите галочку)

Все вложения **необязательны**. Их можно не отмечать — это и есть способ отказаться. Ничего из перечисленного ниже не добавляется в отчёт без отдельной отмеченной галочки.

- **Техснимок** — ограниченный технический контекст: version, locale, theme, current URL, viewport, состояние панели и настройки **без** медиа-изображений, cookies и tokens.
- **Скриншот** — снимок видимой вкладки faceit.com и панели FACEIT UI. На нём могут быть видны ник, аватар и отображаемое содержимое страницы.
- **Список выбранных элементов** — нумерованные технические метаданные элементов, которые вы сами выбрали (селектор / tag / class / геометрия / URL) для диагностики. Это **не** полный HTML/DOM, **не** текст страницы и **не** значения полей ввода.

### Что расширение не отправляет автоматически

- Cookies браузера или FACEIT
- Пароли, токены сессии или платёжные данные
- Сообщения
- Историю просмотров (передаётся только URL текущей страницы)
- Полное содержимое хранилища расширения (темы, импорты, медиа и т.п.)

Перед отправкой форма просит подтвердить, что вы не включили конфиденциальные данные в описание или контактные поля.

## Как обрабатываются Bug Report

Отправленные отчёты передаются по HTTPS через:

1. **Cloudflare Worker** — `https://faceit-ui-intake.actually-question.workers.dev`
2. **Render** — intake backend (`https://faceit-ui-intake.onrender.com`)
3. **Resend** — доставка email разработчику расширения

Отчёты доставляются по email для ручной проверки. FACEIT UI не продаёт пользовательские данные. Данные из Bug Report используются для поддержки и исправления ошибок.

## Ссылка Donate

Кнопка **Donate** открывает внешний сайт в браузере. FACEIT UI не обрабатывает и не передаёт платёжную информацию.

## Удалённый код

FACEIT UI не загружает и не выполняет удалённый JavaScript. Исполняемый код входит в опубликованный пакет расширения (Manifest V3).

## Изменения

Эта политика может обновляться при изменении функциональности FACEIT UI. Дата **Последнее обновление** выше отражает актуальную редакцию.

## Контакты

По вопросам этой политики или FACEIT UI используйте способ связи из карточки расширения в магазине или отправьте Bug Report из панели расширения.
