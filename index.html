# FACEIT UI — Privacy Policy **Last updated: August 30, 2026** FACEIT UI is a browser extension that provides a presentation and customization layer for the FACEIT website. ## Data collection FACEIT UI does not collect, sell, or share personal information. The extension does not collect names, email addresses, passwords, payment information, precise location data, browsing history, or private messages. ## Website content FACEIT UI operates on pages of the FACEIT website in order to modify the visual presentation of the interface. Website content is processed locally in the user's browser and is not transmitted to the developer or to third parties. ## Storage The extension may use the browser's local storage to save user preferences and theme settings. ## Remote code FACEIT UI does not download or execute remote JavaScript code. The extension's executable code is included in the published extension package. ## Third parties FACEIT UI does not sell or transfer user data to third parties. ## Changes This Privacy Policy may be updated when the functionality of FACEIT UI changes. ## Contact For questions regarding this Privacy Policy or FACEIT UI, please use the support/contact method provided on the extension's store listing.
